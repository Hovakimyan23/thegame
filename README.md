# Number Guessing Game

A polished browser-based game where players guess a randomly generated number between 1 and 100. Built with HTML, CSS, and JavaScript.

## Features

- Randomly generated number for each game.
- Tracks the number of attempts per round.
- Saves your best (lowest) score across sessions.
- Live range indicator that narrows as you guess.
- Input validation (only accepts whole numbers 1–100).
- Clean, responsive UI with color-coded feedback (too high / too low / correct).
- No pop-ups — everything happens right on the page.
- Play Again button to start a fresh round instantly.

## How to Play

1. Open `index.html` in your browser.
2. Type a number between 1 and 100 and click **Guess**.
3. Read the hint — "Too high!" or "Too low!" — and guess again.
4. The range bar narrows to help you zero in.
5. When you guess correctly, your attempt count is saved as your best score if it beats the previous one.
6. Click **Play Again** to start a new round.
